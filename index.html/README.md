# Assure Med

## Behavioral Health Revenue Cycle Management Platform

Assure Med is a healthcare SaaS application designed to help behavioral health providers simplify revenue cycle management through an intuitive web-based platform.

### Features

- Claims Submission & Tracking
- Insurance Payment Posting
- Patient Payment Tracking
- Revenue Dashboard
- Claim Follow-Up
- Patient Statements
- Revenue Reporting
- Behavioral Health Billing Workflows
- JSON Claim Export
- 837P Claim Export

### Technology Stack

- JavaScript
- HTML5
- CSS3
- Node.js
- Express.js
- SQLite
- Git
- GitHub
